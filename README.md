# STREAM Sites

Public hub for Donovan Catholic STREAM classroom sites, published at [frankbraski.github.io](https://frankbraski.github.io/).

The page groups every live GitHub Pages site plus two school Google Sites:

- **Leaderboards** — the auto-tour and each class or VIP board
- **MoneyBall** — the standalone scholarships and career-opportunities sign
- **Classroom Apps** — Workshop Reader, FTC Robot Systems Lab, and StopLight
- **Video Library** — the STREAM video tag map
- **School Sites** — STREAM Team and RoboRAMS scholarships (Donovan login required)

This is a user site, so GitHub Pages serves `index.html` from the `main` branch at the root of `https://frankbraski.github.io/`.

To add a site, put a new card in the right section of `index.html` and push to `main`.
